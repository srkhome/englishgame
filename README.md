# 拼讀大富翁（單人網頁版）

一款結合**英文拼讀（phonics）練習**與**大富翁**玩法的單人瀏覽器小遊戲。玩家與電腦對手輪流拼出包含指定字母串的英文單字前進、買地產、收租金，比誰的策略跟字彙量更好！

無需安裝、無需伺服器，用瀏覽器打開 `.html` 檔案就能玩。

## 遊戲目標

輪流拼出英文單字前進、買下地產、升級賺過路費，遊戲進行 **15 輪**後，依「代幣 + 地產價值」計算總分，分數最高的玩家獲勝！

## 開始設定

- 每局固定 **3 位玩家**，可自選 1–3 位人類玩家，人數不足時由電腦玩家自動補齊。
- 棋子顏色固定為 **藍 / 紅 / 綠**，並以側面立牌造型的小人呈現。
- 每次開新局，遊戲會從 **16 組小學常用字根**（如 at、an、og、un、ig、ay、ee、ook、ing、ack、ock、ip、ot、ell、ug、ine）中**隨機抽選 8 組**上場，所以每一局出現的字母組合都不一樣，重複遊玩不會膩。

## 每回合的流程

1. 系統隨機抽出一個字母串（例如 `at`）。
2. 限時 **45 秒**，輸入一個「包含這個字母串」的英文單字。
3. **先看拼字結果，再決定要不要擲骰子：**
   - ✅ **拼對了**：擲一顆六面骰子（1–6 點），骰到幾點就前進幾格。
   - ❌ **拼錯或超時沒作答**：**不擲骰子**，直接**停在原地不動**，換下一位玩家。
4. 移動後根據停留的格子觸發對應效果（見下方「各特殊格效果」）。

## 單字規則

- 單字只要「包含」當回合抽到的字母串就算數，**不限位置**——字首、字中、字尾都可以。
  - 例如字母串是 `at`：`fat`（字尾）、`attack`（字首）、`water`（字中）都算正確。
- 系統內建**教育部國小 1200 必背單字**等兩千多個常見字，完全離線也能立即判斷正確與否；只有極少數不在內建字庫的生僻字，才會嘗試連線字典（dictionaryapi.dev）查詢確認，並附有逾時保護，不會卡住畫面。
- 同一個單字用過之後會進入**冷卻**，需要間隔 **5 個回合**之後才能再次使用同一個字。
- 想不到單字時可以按「需要提示」，但這次**不擲骰子、固定只前進 1 格**，且每位玩家一場遊戲最多可使用 **10 次**提示。
- 拼字失敗時，紀錄欄一律會清楚顯示「你拼的是『xxx』」＋失敗原因，方便知道自己是哪裡拼錯。

## 地產：購買、升級、過路費

| 情境 | 說明 |
| --- | --- |
| 走到空地 | 可以挑戰拼字買下地產；拼錯就不會買到，維持空地。 |
| 走到自己的地產 | 可以挑戰拼字升級（小屋 → 大屋 → 飯店）；累積使用過的不同單字數量越多，等級越高，過路費也越高。 |
| 走到別人的地產 | 需支付過路費，也可以選擇挑戰拼字，拼對就免付租金。 |

已被買下的地產格會顯示與該玩家棋子相同的顏色，方便一眼辨認。

| 格子 | 效果 |

| 🏁 出發 GO | 只要走過或停在出發點，就能獲得 **2 枚代幣**獎勵。 |
| 📖 複習關 | 純粹休息一下，沒有任何懲罰或獎勵，直接換下一位玩家。 |
| ➡️ 前往複習關 | 被直接送到複習關格，並且**下一輪暫停一次**，不能行動。 |

| 🃏 拼讀挑戰卡 | 隨機抽到一種效果：聽音辨字（+1 幣）、造句小挑戰（前進 1 格）、快問快答（+1 幣）、反義詞挑戰（前進 2 格）、複習加分（+2 幣）。 |
| 💰 字彙寶箱卡 | 隨機抽到一種效果：單字量進步獎（+2 幣）、幸運字卡（隨機一塊地產免費升級，沒有地產則改領 +2 幣）、小老師加分（+1 幣）、拼讀失誤（被送回複習關並暫停一輪）、詞彙大挑戰（+3 幣）。 |

## 破產與遊戲結束

- 若玩家代幣不足以支付過路費，且名下有地產可變賣，會被**強制變賣一塊地產**抵債。
- 若玩家代幣不足、且名下**已無地產可變賣**，即視為**破產**。
- ⚠️ **只要有任何一位玩家破產，遊戲會立刻提前結束**，不會等其他玩家繼續玩完，直接依當下每個人的「代幣 + 地產價值」結算名次。
- 若沒有人破產，遊戲會在進行滿 **15 輪**後自動結束並結算。

## 計分方式

```
總分 = 代幣數量 + 所有已擁有地產的價值總和
```

## 技術說明

- 純前端單一 HTML 檔案（HTML + CSS + JavaScript），無需建置流程、無需伺服器，直接用瀏覽器開啟即可遊玩。
- 內建約 2,000+ 字的離線英文單字庫（含教育部國小 1200 必背單字），拼字判斷優先使用本機字庫，不依賴網路；只有極少數生僻字才會嘗試連線 [dictionaryapi.dev](https://dictionaryapi.dev/) 做二次確認。
- 電腦玩家（AI）具備約 78% 的拼字成功率，並會避開仍在冷卻中的單字。
- 棋子以 SVG 繪製成側面立牌造型，移動時具備逐格跳躍動畫。
