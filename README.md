# 拼讀大富翁（單人網頁版）

一款結合**英文拼讀（phonics）練習**與**大富翁策略玩法**的單人瀏覽器小遊戲。玩家與電腦對手輪流拼出包含指定字母串的英文單字前進、買地產、收租金、集卡、拚成就，比誰的策略跟字彙量更好！

無需安裝、無需伺服器，用瀏覽器打開 `.html` 檔案就能玩。

## 遊戲目標

輪流拼出英文單字前進、買下地產、升級賺過路費，遊戲進行 **15 輪**、並完成第 15 輪後的「最終 BOSS」挑戰，依「代幣 + 地產價值」計算總分，分數最高的玩家獲勝！

## 開始設定

- 每局固定 **3 位玩家**，可自選 1–3 位人類玩家，人數不足時由電腦玩家自動補齊。
- 棋子顏色固定為 **藍 / 紅 / 綠**，並以側面立牌造型的小人呈現，移動時有逐格跳躍動畫。
- **難度選擇（簡單／普通／困難）**：會同時影響
  - 電腦玩家拼字成功率：60% / 75% / 90%
  - 你的提示規則：詳見〈單字規則〉
  - 拼字限時：會隨回合遞減（見下）
- **電腦玩家個性**：每位電腦玩家開局隨機拿到一種個性，名字旁邊會顯示標籤：
  - 🤓 學霸：成功率較高，但比較少買地
  - 💰 商人：看到地一定買
  - 😈 搗蛋鬼：很愛挑戰升級與免租
  - 🏰 地產王：一定升級自己的地
  - 🐢 烏龜：前期較弱、後期爆發
- 每次開新局，會從 **16 組小學常用字根**（at、an、og、un、ig、ay、ee、ook、ing、ack、ock、ip、ot、ell、ug、ine）中**隨機抽選 8 組**上場，所以每一局出現的字母組合都不一樣。
- **每局隨機事件**：開局會隨機挑 3 個回合套用天氣／校園事件——🌧 下雨（全體移動 -1 步）、☀️ 晴天（全體移動 +1 步）、📚 校慶（學校地產能力 ×2）。

## 每回合的流程

1. 系統隨機抽出一個字母串（例如 `at`）。
2. 限時作答（時限依回合遞減：第 1–5 輪 45 秒、第 6–10 輪 35 秒、第 11–15 輪 25 秒），輸入一個「包含這個字母串」的英文單字。
3. **先看拼字結果，再決定要不要擲骰子：**
   - ✅ **拼對了**：依單字長度骰不同的骰子（見下）。
   - ❌ **拼錯或超時沒作答**：**不擲骰子**，直接**停在原地不動**，換下一位玩家，並附上教學提示（示範一個符合條件的正確單字）。
4. 移動後根據停留的格子觸發對應效果。
5. 每 5 輪（第 5、10、15 輪）開始前會插入一次 **👑 Boss Round** 全員挑戰。

## 骰子規則（依單字長度）

| 單字長度 | 擲骰方式 |
| --- | --- |
| 3 個字母 | 骰 1 顆骰子（1–6 點） |
| 4–5 個字母 | 骰 2 顆，取較高的一顆 |
| 6 個字母以上 | 骰 2 顆，兩顆相加（最高 12 步） |

拼字越長，前進潛力越大！使用提示成功則固定只前進 1 格，不擲骰子。

## 單字規則

- 單字只要「包含」當回合抽到的字母串就算數，**不限位置**——字首、字中、字尾都可以（例如 `at` 可以是 `fat`、`attack`、`water`）。
- 系統內建**教育部國小 1200 必背單字**等兩千多個常見字，完全離線即可判斷正確與否；只有極少數不在字庫的生僻字，才會嘗試連線字典（dictionaryapi.dev）二次確認，並有逾時保護。
- 同一個單字用過之後會進入**冷卻**，需間隔 **5 個回合**後才能再次使用。
- **提示規則依難度不同**：

  | 難度 | 提示次數 | 內容 |
  | --- | --- | --- |
  | 簡單 | 5 次 | 每次都直接顯示完整單字 |
  | 普通 | 5 次 | 前 2 次完整單字，後 3 次只給開頭字母 |
  | 困難 | 3 次 | 都只給開頭字母 |

  擁有 📚 圖書館地產可再 +1 次提示；用了提示這次固定只前進 1 格。
- **🎲 幸運骰**：每位玩家整場遊戲有一次機會，可以不拼字，直接自選 1–6 步數前進。

## 地產：購買、升級、過路費

| 情境 | 說明 |
| --- | --- |
| 走到空地 | 先挑戰拼字，拼對後可以自由選擇「要不要花代幣買下」，不是拼對就一定要買。 |
| 走到自己的地產 | 可以挑戰拼字升級（小屋 → 大屋 → 飯店）；累積使用過的不同單字數量越多，等級越高，過路費也越高。 |
| 走到別人的地產 | 需支付過路費，也可以選擇挑戰拼字，拼對就免付租金。 |

已被買下的地產格會顯示與該玩家棋子相同的顏色。

## 地產特色能力

每塊地產格右上角有一個小圖示，代表這個位置固定擁有的特色能力（無論當局是哪個字根家族），能力強度會隨地產等級（小屋/大屋/飯店）越升越強：

| 圖示 | 名稱 | 效果 |
| --- | --- | --- |
| 🌲 | 森林 | 過路費 +2（依等級加碼，銀行額外補貼地主） |
| 🏫 | 學校 | 在此升級成功額外 +1 幣（依等級加碼） |
| 📚 | 圖書館 | 擁有者提示次數上限 +1 |
| 🏪 | 商店 | 在此購買地產費用 -1 |
| 🏦 | 銀行 | 擁有者經過出發點額外加碼代幣 |
| 🗼 | 燈塔 | 擁有者擲骰移動步數額外加碼 |
| 🌷 | 花園 | 計分時地產鑑價額外加分 |
| 🏰 | 城堡 | 過路費倍率提高 |

## 各特殊格效果

- **出發 GO**：走過或停在出發點獲得 2 枚代幣（🏦 銀行地產可加碼）。
- **複習關**：純粹休息，無懲罰無獎勵。
- **前往複習關**：被送到複習關，下一輪暫停一次。
- **單字獎勵站**：已有地產則隨機免費升級一塊；沒有地產則領 3 枚代幣。
- **拼讀挑戰卡**：聽音辨字／造句小挑戰／快問快答／反義詞挑戰／複習加分，五選一隨機效果。
- **字彙寶箱卡**：單字量進步獎／幸運字卡／小老師加分／拼讀失誤／詞彙大挑戰／**🏴‍☠️ 海盜來了**（50% 機率偷走別人一塊低等級地產，失敗損失 2 枚代幣），六選一隨機效果。
- **👑 Boss Round**：每 5 輪開始前，全員挑戰同一字根，成功前三名獲得 5／3／1 枚代幣。同時棋盤上會出現一塊 **👑 超級地產**，第一個拼對的人可直接免費奪得永久五星地產（過路費 +5）。

## 進階獎勵機制

- **🔥 Combo 連續答對**：連續成功第 2 次 +1 步、第 3 次 +2 步、第 4 次 +3 幣、第 5 次隨機一塊地產免費升級（之後歸零重新累積）；失敗一次即歸零。
- **👯 家族連擊**：連續兩回合抽到同一字根家族，第 2 次 +2 幣；連續三次同家族，第 3 次直接隨機升級一塊地產。
- **⛓️ 字母連鎖**：這次的單字同時包含「上一回合的字根」和「這次的字根」（例如 at→ack，拼出 attack），額外 +2 步。
- **🧬 字母融合**：拼出的單字同時包含這次字根和你已擁有地產的另一個字根，額外免費升級那塊地產。
- **📖 單字收藏冊**：集滿 20 個不同單字獲得寶箱獎勵 +5 幣。
- **🌈 字母串家族收藏冊**：集滿單一字根家族的收藏目標，永久 +1 骰子點數（每家族限一次）。
- **💎 稀有字獎勵**：像 `elephant`、`computer`、`beautiful` 這類較長的字，全場第一個拼出的人額外 +5 幣（每字全場限一次）。
- **🔥 最終 BOSS**：第 15 輪結束後，隨機抽 3 個字根，每位玩家要拼出「同時包含至少兩個字根」的單字（例如 at + ing = eating），成功額外 +20 分。
- **🏅 成就系統（共 15 種）**：拼字王、長字高手、地產大亨、神來一筆、不放棄、連續10次答對、存到50元、拼出100字、一回合走12步、不用提示通關、Boss Killer、家族收藏達人、全家族收藏、五回合內買三塊地、收到10元以上租金。達成時會在紀錄欄公告，並顯示在結算畫面。

## 破產與遊戲結束

- 代幣不足以支付過路費時：若名下有地產，會被強制變賣一塊地產抵債。
- 若名下**已無地產可變賣**，視為**破產**：直接扣除當下代幣的 **50%** 作為懲罰，但**不會出局**，可以繼續遊戲。
- 遊戲在完成 15 輪並結束「最終 BOSS」挑戰後結束並結算，不會因破產而提前結束。

## 計分與星級評價

```
總分 = 代幣數量 + 所有已擁有地產的價值總和（🌷 花園地產額外加成）
```

結算畫面除了總分排名，還會依「拼字能力、家族收藏、地產、成就、Boss 表現」五個面向，給每位玩家 **⭐ 1–5 顆星**評價與稱號：

## 技術說明

- 純前端單一 HTML 檔案（HTML + CSS + JavaScript），無需建置流程、無需伺服器，直接用瀏覽器開啟即可遊玩。
- 內建約 2,000+ 字的離線英文單字庫（含教育部國小 1200 必背單字），拼字判斷優先使用本機字庫，不依賴網路；只有極少數生僻字才會嘗試連線 [dictionaryapi.dev](https://dictionaryapi.dev/) 做二次確認（附逾時保護）。
- 棋子以 SVG 繪製成側面立牌造型，移動時具備逐格跳躍動畫；地產格會顯示特色能力小圖示與超級地產皇冠標記。
- 已修正拼字倒數計時與手動送出之間的競速問題（避免同一次挑戰被重複處理），並在每次開新局時重置全域挑戰狀態，確保「再玩一次」永遠乾淨可靠。
